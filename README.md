# Dikaios Amanah

> **"Dikaios"** (δίκαιος) — Greek for *just* or *righteous* · **"Amanah"** — Arabic for *trust* or *trustworthiness*

A Software Engineering Lab project focused on building a trustworthy, transparent, and auditable platform for justice and accountability.

---

## 📌 Current Phase

> **Phase 3 — Software Requirements Specification (SRS) · IN PROGRESS**

## 📋 Project Overview

**Dikaios Amanah** is a university Software Engineering Lab project aimed at designing and (later) implementing a platform that embodies the principles of justice (*dikaios*) and trust (*amanah*). The project applies a full Software Engineering lifecycle — from requirements gathering through design, implementation, testing, and deployment.

This repository serves as the central hub for all project documentation, design artefacts, and (eventually) source code.
