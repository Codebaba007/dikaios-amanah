\subsection{Overview}

The proposed system follows a modern three-tier web application architecture consisting of a presentation layer, an application layer, and a data layer. This architecture promotes modularity, maintainability, scalability, and security by separating user interaction, business logic, and persistent data storage.

The architecture has been designed to support future expansion while remaining technically feasible for implementation as a university-level Minimum Viable Product (MVP).

%----------------------------------------------------

\subsection{Presentation Layer}

The Presentation Layer provides the graphical user interface through which users interact with the platform.

The frontend will be developed using React.js and consists of three dedicated user portals:

\begin{itemize}
\item Business Owner Portal
\item Investor Portal
\item Administrator Dashboard
\end{itemize}

The interface communicates with backend services using RESTful APIs over HTTPS.

%----------------------------------------------------

\subsection{Application Layer}

The Application Layer contains the business logic responsible for processing user requests and enforcing business rules.

This layer will be implemented using Node.js and Express.js.

Major responsibilities include:

\begin{itemize}

\item User Authentication

\item Authorization

\item Business Verification

\item Investment Management

\item Risk Assessment

\item Profit Distribution Logic

\item Document Management

\item Audit Management

\end{itemize}

%----------------------------------------------------

\subsection{Data Layer}

The Data Layer stores all operational data required by the platform.

PostgreSQL serves as the primary relational database for users, businesses, investments, contracts, and transaction records.

Firebase Storage stores uploaded business documents and supporting files.

The Permissioned Trust and Audit Layer stores cryptographic hashes and timestamps of critical platform events to provide tamper-evident audit records.

%----------------------------------------------------

\subsection{Security Architecture}

Security is implemented through multiple independent layers.

\begin{itemize}

\item HTTPS Communication

\item JWT Authentication

\item Role-Based Access Control

\item bcrypt Password Hashing

\item SHA-256 Document Hashing

\item Secure File Storage

\item Audit Logging

\item Permissioned Trust and Audit Layer

\end{itemize}

This layered security model minimizes the impact of individual security failures while improving overall system resilience.
