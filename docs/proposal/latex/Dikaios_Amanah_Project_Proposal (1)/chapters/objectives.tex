\subsection{General Objective}

The primary objective of Dikaios Amanah is to design and develop a secure, transparent, and ethically governed web-based investment platform that enables verified Small and Medium Enterprises (SMEs) in Bangladesh to connect with verified retail investors through Musharakah-based partnership financing. The project aims to demonstrate the practical application of modern Software Engineering principles while addressing real-world challenges related to transparency, trust, security, and ethical investment.

%----------------------------------------------------

\subsection{Specific Objectives}

The project seeks to achieve the following objectives:

\begin{enumerate}
    \item Develop a responsive web application that supports separate interfaces for business owners, investors, and administrators.

    \item Implement secure user authentication and role-based authorization to protect system resources and user accounts.

    \item Design a structured business verification process that improves investor confidence before investment decisions are made.

    \item Provide a secure document management system for storing and managing business verification documents.

    \item Enable SMEs to create, manage, and monitor Musharakah-based investment campaigns.

    \item Allow investors to discover verified businesses, review investment opportunities, and monitor their investment portfolio.

    \item Record critical platform events using a Permissioned Trust and Audit Layer to improve transparency and provide tamper-evident audit records.

    \item Apply secure software engineering practices, including password hashing, document integrity verification, secure session management, and activity logging.

    \item Develop a technically feasible Minimum Viable Product (MVP) suitable for demonstration as a final-year Software Engineering capstone project.

\end{enumerate}

%----------------------------------------------------

\subsection{Expected Deliverables}

Upon successful completion, the project is expected to deliver:

\begin{itemize}

\item A fully functional web-based MVP.

\item Separate dashboards for Business Owners, Investors, and Administrators.

\item Business registration and verification module.

\item Investor registration and KYC module.

\item Investment campaign management system.

\item Risk assessment and approval workflow.

\item Secure authentication and authorization system.

\item Permissioned Trust and Audit Layer prototype.

\item Complete Software Requirements Specification (SRS).

\item UML diagrams and software design documentation.

\item User documentation and project report.

\end{itemize}

%----------------------------------------------------

\subsection{Success Criteria}

The proposed project will be considered successful if it is able to:

\begin{itemize}

\item Successfully authenticate and authorize different categories of users.

\item Enable verified businesses to publish investment campaigns.

\item Allow investors to browse and participate in verified investment opportunities.

\item Maintain secure storage and verification of business documents.

\item Demonstrate transparent recording of critical events through the Permissioned Trust and Audit Layer.

\item Provide an intuitive and responsive user interface.

\item Demonstrate compliance with the defined functional and non-functional requirements of the proposed system.

\end{itemize}
