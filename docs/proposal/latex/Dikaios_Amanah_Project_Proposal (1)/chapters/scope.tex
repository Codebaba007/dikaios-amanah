\subsection{Overview}

The scope of Dikaios Amanah defines the boundaries of the proposed system and identifies the features that will be included in the Minimum Viable Product (MVP). The project focuses on designing and developing a secure, web-based platform that enables transparent and ethical investment between verified Small and Medium Enterprises (SMEs) and verified retail investors using the Musharakah partnership model.

The project emphasizes Software Engineering principles, secure system design, role-based access control, document verification, and transparent audit mechanisms while remaining technically feasible for implementation as a final-year capstone project.

%----------------------------------------------------

\subsection{Functional Scope}

The proposed system will include the following functional modules:

\begin{itemize}

\item User Registration and Authentication

\item Business Owner Dashboard

\item Investor Dashboard

\item Administrator Dashboard

\item Business Profile Management

\item Investor KYC Verification

\item Business Verification

\item Secure Document Upload

\item Investment Campaign Creation

\item Campaign Browsing

\item Investment Tracking

\item Profit Declaration

\item Portfolio Management

\item Notification System

\item Activity Logging

\item Permissioned Trust and Audit Layer

\end{itemize}

%----------------------------------------------------

\subsection{Technical Scope}

The project will be developed using modern web technologies and secure software engineering practices.

The planned technology stack includes:

\begin{itemize}

\item React.js for the frontend.

\item Node.js and Express.js for backend services.

\item PostgreSQL for relational database management.

\item Firebase Storage for secure document storage.

\item JSON Web Token (JWT) for authentication.

\item bcrypt for password hashing.

\item SHA-256 for document integrity verification.

\item Git and GitHub for version control.

\item A Permissioned Trust and Audit Layer for recording critical system events.

\end{itemize}

The proposed architecture follows a layered design that separates presentation, business logic, security, and data management to improve maintainability and scalability.

\subsection{Project Stakeholders}

The proposed system involves three primary stakeholder groups.

\begin{enumerate}

\item Business Owners

Businesses seeking ethical investment opportunities for expansion and operational growth.

\item Retail Investors

Individuals interested in participating in verified Musharakah-based investment opportunities.

\item System Administrators

Authorized personnel responsible for user verification, business approval, system monitoring, and platform administration.

\end{enumerate}

%----------------------------------------------------

\subsection{Project Limitations}

To maintain feasibility within the academic timeframe, several features are intentionally excluded from the MVP.

The proposed system does not include:

\begin{itemize}

\item Live banking integration.

\item Real payment gateway integration.

\item BSEC regulatory compliance implementation.

\item AI-based fraud detection.

\item AI-powered risk prediction.

\item Production Hyperledger Fabric deployment.

\item Native Android or iOS mobile applications.

\item Automated smart contract execution.

\end{itemize}

These features are identified as future enhancements rather than core project requirements.

%----------------------------------------------------

\subsection{Project Assumptions}

The development of the proposed system is based on the following assumptions.

\begin{itemize}

\item Users possess basic digital literacy.

\item Internet connectivity is available.

\item Businesses provide authentic documentation.

\item Administrators perform verification responsibly.

\item The project is developed for academic demonstration purposes.

\item Simulated investment transactions are used during system testing.

\end{itemize}

\subsection{Future Scope}

Although the MVP focuses on demonstrating the complete investment workflow, the proposed architecture has been designed to support future expansion.

Potential future enhancements include:

\begin{itemize}

\item Mobile application development.

\item Integration with digital payment gateways.

\item Hyperledger Fabric deployment.

\item AI-assisted business risk assessment.

\item Automated regulatory reporting.

\item Smart contract automation.

\item Investor recommendation system.

\item Multi-language support.

\item Real-time analytics dashboard.

\item Integration with government business verification services.

\end{itemize}

These enhancements would enable Dikaios Amanah to evolve into a production-ready ethical investment platform while maintaining compatibility with the proposed system architecture.
