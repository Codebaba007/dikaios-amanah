\subsection{Overview}

A project timeline provides a structured schedule for completing all planned activities within the academic semester. The timeline follows an iterative Software Development Life Cycle (SDLC), allowing each phase to build upon the previous one while providing sufficient time for testing, documentation, and revisions.

Since Dikaios Amanah is being developed as a solo capstone project, the development schedule prioritizes the implementation of core MVP features before optional enhancements. This approach reduces project risk and ensures that the essential system components are completed within the available timeframe.

\subsection{Milestones}

The project is expected to achieve the following milestones during development.

\begin{itemize}

\item Approval of the project proposal.

\item Completion of the Software Requirements Specification (SRS).

\item Completion of system architecture and database design.

\item Development of frontend and backend modules.

\item Integration of security mechanisms.

\item Implementation of the Permissioned Trust and Audit Layer.

\item Completion of testing and debugging.

\item Final project demonstration.

\item Submission of project documentation.

\end{itemize}

\subsection{Timeline Summary}

The proposed timeline allocates sufficient time for planning, development, testing, documentation, and presentation while maintaining a realistic workload for a solo developer. The phased schedule supports incremental development and allows continuous evaluation of project progress throughout the Software Development Life Cycle.
